# Demo Bank – poligon do nauki GA4

1. Załóż na GitHubie **publiczne** repozytorium `bank-ga4-demo` i wgraj tu całą zawartość tego folderu (z ukrytym `.github`).
2. GA4: Admin → Utwórz usługę → Strumień danych **Web** → skopiuj Measurement ID (`G-…`) i wklej do `docs/config.js`.
3. GitHub: Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/docs`.
4. Poczekaj ok. 2 min, otwórz `https://TWOJ_LOGIN.github.io/bank-ga4-demo/?debug` i sprawdź Realtime/DebugView w GA4.
5. Actions → *traffic* → Run workflow (domyślnie 40 sesji). Dalej leci sam 3 razy dziennie.
6. Scenariusze: `SCENARIUSZE.md`.
